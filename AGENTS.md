# Blog Assets — Agent Rules

This is a static asset repository. Do not add a scraping runtime here.

For any research, web search, or page scraping needed while working on these
assets, use the globally installed `web-fetch` MCP tools (`web_search` and
`web_scrape`). They try zero-cost tools first and may automatically make one
budgeted Firecrawl attempt only when the free tools are unavailable or return
unusable content. A clean search with no results is not a reason to spend
Firecrawl credits.

Do not add a direct Firecrawl SDK, HTTP API call, or official Firecrawl MCP. If
`web-fetch` is not surfaced, repair the shared provider configuration rather
than adding a paid client to this repository.
